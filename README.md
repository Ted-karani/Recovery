# Forward
My personal app for building my life. React + Vite. Data stays in my phone's browser (localStorage).

## Run it
1. Open the `forward` folder in VS Code.
2. Open the terminal (Ctrl + `).
3. Run `npm install`, wait until it finishes.
4. Run `npm run dev` and open the link it prints.

## Put it online (one link, always available)
1. Create an empty repo on GitHub, then in the terminal run: `git init`, `git add .`, `git commit -m "Forward"`, `git branch -M main`, `git remote add origin <your repo url>`, `git push -u origin main`.
2. On vercel.com choose Add New > Project, pick the repo, keep the defaults (Vite is detected), press Deploy.
3. Open the link on your phone and use Add to Home Screen.
